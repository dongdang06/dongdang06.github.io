# Portfolio Cá Nhân

Website giới thiệu của **Đặng Bá Đông**, sinh viên ngành Hệ thống Thông tin tại trường Đại học Công nghệ Thông tin (UIT).

## Tính năng chính
- **Single Page Application (SPA):** Chuyển giữa các mục nhanh chóng mà không cần load lại trang.
- **Lightbox Gallery:** Nhấp vào hình ảnh ở phần thư viện để phóng to.
- **Responsive:** Hiển thị tốt trên cả máy tính và điện thoại.

## Cấu trúc thư mục
- `index.html`: File giao diện chính của trang web.
- `assets/css/style.css`: File định dạng giao diện (CSS).
- `assets/js/main.js`: File xử lý sự kiện chuyển tab và mở lightbox xem ảnh (JS).
- `images/`: Thư mục lưu trữ hình ảnh của trang web.

## Cách chạy dự án
1. Tải toàn bộ mã nguồn về máy.
2. Mở trực tiếp file `index.html` bằng trình duyệt web (hoặc sử dụng extension Live Server trên VS Code).

## Bản quyền nội dung
- Nội dung và mã nguồn phục vụ mục đích học tập và tham khảo tại UIT, không sử dụng cho mục đích thương mại. Các thông tin cá nhân (như dự án, kinh nghiệm làm việc) chỉ là thông tin giả định phục vụ cho việc thực hành môn học.
